# FPSHOOTER 🌆🔫

A complete 3D First-Person Shooter developed with **Godot 4.7** and **Blender 5.3**.

---

## 🎮 Features
- **Sunset Atmosphere & City Skyline**:
  - Warm golden-hour sunset lighting with physical sky atmosphere, volumetric fog, and glowing city dusk tones.
  - Urban cityscape containing towers, commercial buildings, street lamps, barriers, and firing range drone targets.
- **2 Weapons Built in Blender**:
  - **Pistol (Semi-Automatic)**: High precision sidearm with holographic sight and light/spark VFX.
  - **Assault Rifle (Full-Automatic)**: Rapid fire carbine with custom magazine, optical scope, and intense muzzle flash effects.
- **Weapon & Combat VFX**:
  - Dynamic Muzzle Flash (OmniLight3D burst + custom GPUParticles3D spark cone).
  - Recoil animation and procedural weapon sway.
  - Impact Spark Particle VFX on hit surfaces.
  - Destructible Target Drones with hit-reactions and explosion effects.
- **First-Person Controller**:
  - Smooth mouse-look with vertical clamp.
  - Full movement (WASD), sprinting (Shift), and jump physics.
  - In-game HUD with real-time weapon indicator, ammo counters, crosshair, and control guide.

---

## 🕹️ Controls
| Action | Key / Input |
|---|---|
| **Move** | `W`, `A`, `S`, `D` |
| **Look** | Mouse |
| **Sprint** | `Shift` (Hold) |
| **Jump** | `Space` |
| **Fire** | `Left Mouse Button` |
| **Switch to Pistol** | `1` |
| **Switch to Rifle** | `2` |
| **Reload** | `R` |
| **Capture / Release Cursor** | `Esc` |

---

## 🛠️ Built With
- **Godot Engine 4.7**: Physics, scenes, particles, audio/visual pipelines, and GDScript gameplay.
- **Blender 5.3**: 3D asset modeling, materials, and GLTF/GLB export pipeline.
